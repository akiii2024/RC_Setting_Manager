# OpenWeather公式ロゴ

- 配布元: https://openweathermap.org/faq （License節の公式ロゴダウンロード）
- 取得URL: https://openweathermap.org/payload/api/files/file/logo_files.zip
- ZIP内: `Logo files/Master logo/RGB (for screen)/OpenWeather-Master-Logo RGB.png`
- 取得日: 2026-10-22
- `openweather.png` は原文書のPNGを加工せず抽出したもの。OpenWeatherの商標・ロゴをFreeプランの帰属表示のために使用する。アプリ独自のロゴとしては利用しない。

公式指定の文言、公式サイトへのリンクと一緒に表示する。APIアクセスは不要で、ロゴはアプリに同梱する。
